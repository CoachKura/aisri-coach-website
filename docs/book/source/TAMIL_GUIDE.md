# Tamil translation guide — AKURA World Athlete Research Book

Audience: Tamil-speaking coaches, club runners, college athletes and sports-science students in Tamil Nadu.
Style: clear, modern, natural written Tamil (as in good Tamil science journalism), not archaic literary Tamil
and not word-for-word literal. Short sentences. Warm, respectful, coach-to-coach tone. Keep the author's
scientific humility and all caveats exactly.

## Technical terms
Use the author's own mixed style: established Tamil words where they are common, and keep precise scientific
terms in English (Latin script) where Tamil readers in sport use them. On FIRST use in each chapter give
Tamil + English in brackets, e.g. இதயத் துடிப்பு (heart rate), then use the Tamil alone.
Keep these in English script always: VO₂max, VDOT, AEI, AEI-Fitness, AEI-Readiness, AISRi, HRV, RPE, WBGT,
EPO, ECG, ATP, Hb, pace (you may write "பேஸ் (pace)" first time), threshold, lactate, 5K/10K/HM, km, min/km, mmHg, °C.

Glossary (use consistently):
- endurance = சகிப்புத்திறன்   - athlete = விளையாட்டு வீரர் (use "வீரர்/வீராங்கனை" neutrally as "வீரர்")
- coach = பயிற்சியாளர்   - training = பயிற்சி   - recovery = மீட்சி   - readiness = தயார்நிலை
- heat = வெப்பம்   - humidity = ஈரப்பதம்   - altitude = உயரம் (high altitude = உயரமான பகுதி)
- heat acclimation = வெப்பப் பழக்கப்படுத்தல்   - haemoglobin = ஹீமோகுளோபின்   - plasma = பிளாஸ்மா
- red blood cells = இரத்தச் சிவப்பணுக்கள்   - oxygen = ஆக்சிஜன்   - heart = இதயம்   - lungs = நுரையீரல்
- stroke volume = இதயத் துடிப்புக் கொள்ளளவு (stroke volume)   - cardiac output = இதய வெளியீடு (cardiac output)
- running economy = ஓட்டச் சிக்கனம் (running economy)   - durability = நீடித்திறன் (durability)
- mitochondria = மைட்டோகாண்ட்ரியா   - glycogen = கிளைகோஜன்   - hypothesis = கருதுகோள்   - data = தரவு
- measurement = அளவீடு   - evidence = சான்று   - myth = கட்டுக்கதை   - marathon = மாரத்தான்
- intensity = தீவிரம்   - load = சுமை   - protocol = நெறிமுறை (protocol)   - validation = சரிபார்ப்பு
- confidence = நம்பகத்தன்மை   - long run = நீண்ட ஓட்டம்   - interval = இடைவெளிப் பயிற்சி
- Intensity domains: Recovery = மீட்சி, Aerobic = ஏரோபிக், Endurance = சகிப்பு, Threshold = த்ரெஷோல்ட், Power = சக்தி, Speed = வேகம்
Place names in Tamil: சென்னை, பெங்களூரு, ஊட்டி, கொடைக்கானல், கோயம்புத்தூர், மதுரை, கொச்சி. Kenya = கென்யா, Ethiopia = எத்தியோப்பியா.
Researcher names stay in English script (e.g. Joyner & Coyle, Levine, Gore).

## FORMAT RULES (a parser reads the file — follow exactly)
- Keep every structural marker EXACTLY in English at the start of the line: `PART`, `PARTINTRO:`, `##`, `###`,
  `- `, `1)` / `1.`, `|`, `KEY:`, `COACH:`, `FIELD:`, `MYTH:`, `QUOTE:`, `CHECK:`, `FIG:`, `FRONTMATTER`, `BACKMATTER`, `REFS:`.
- `PART XVII — THE AKURA TOOLKIT`: keep `PART <roman numeral> — ` in English, translate only the title after the dash.
- Chapter headings: keep the number: `## 85. <Tamil title>`. Front/back matter headings (`## Author's Note`) → translate the title.
- FIELD boxes: steps are separated by ` ; ` (space-semicolon-space). Keep those separators exactly.
- MYTH: keep ` || ` between myth and evidence.
- QUOTE: keep ` — Kura` attribution as ` — குரா (Kura)`. The existing Tamil quote in Chapter 82 stays unchanged.
- FIG lines: `FIG: filename.png | caption` — keep the filename exactly, translate only the caption.
- Tables: keep the same number of `|` cells in every row; translate words, keep numbers, times and units unchanged.
- `**bold**` markers: keep.
- REFS: section: copy everything after `REFS:` VERBATIM in English (do not translate references).
- One element per line, blank line between elements, no hard wraps. Translate EVERYTHING else; do not summarise or skip.
